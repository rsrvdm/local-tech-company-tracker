# Local Tech Company Tracker

Persistent V1 operating system for the sales pipeline, clients/projects, tasks, follow-ups and prospect website audits. Records save to `localStorage` in the current browser.

Dan Amato Landscaping is seeded as Project #001. The existing Dan preview remains a separate project and is linked from the tracker.

## Website Auditor V1

- Add a new prospect or select an existing record.
- Score seven website categories and save issues, opportunities, architecture, next actions and a copy-ready outreach angle.
- Completed audits move the shared record to **Audited** and show their score in Pipeline.
- Generate and save a structured demo brief with hero, sections, service pages, proof, CTAs, SEO priorities and fact/photo placeholders.
- Dan Amato Landscaping and Spruced Up Pressure Cleaning are seeded examples.

Audits are manual/semi-manual in V1. The tracker does not crawl websites or call AI services, so findings and business facts must be verified before contacting a prospect.

Live tracker: https://rsrvdm.github.io/local-tech-company-tracker/
